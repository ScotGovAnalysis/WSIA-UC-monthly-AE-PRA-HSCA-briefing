# Monthly A&E PRA - HSCA Briefing

**Unscheduled Care Analysis, Whole Systems Intelligence Analysis (WSIA), Directorate for Chief Operating Officer (DCOO)**

## Overview

The Unscheduled Care Analysis team within Whole Systems Intelligence Analysis (WSIA) produce a briefing on the monthly Accident & Emergency (A&E) statistics published by Public Health Scotland. The briefing forms part of the Health and Social Care Analysis (HSCA) pre-release access (PRA) pack circulated to authorised recipients ahead of publication. Due to the short turnaround between receiving the PRA data and producing the briefing, the process has been automated where possible.

This repository contains the code for a Reproducible Analytical Pipeline (RAP) written in R. The pipeline automates the production of briefing materials using the latest monthly PRA dataset.

## The RAP

The RAP:

- Processes the latest monthly A&E PRA data.
- Produces briefing outputs in the approved HSCA briefing format.
- Generates processed datasets suitable for responding to ad hoc analytical requests.
- Creates supporting outputs for the FMQ and SCANCE.
- Supports a consistent, reproducible and auditable analytical process.

## Repository Contents

This repository contains the scripts, functions and documentation required to run the pipeline. Input data, outputs and other sensitive files are excluded from version control and are not stored in GitHub.
